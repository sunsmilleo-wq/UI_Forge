# UiForge — редактор интерфейсов Perfect World

Визуальный редактор xml-файлов интерфейса игры: окно с картинками из игры, перетаскивание и изменение размера
мышью, панель свойств, выбор цвета, поиск по всем файлам и код XML, который меняется вместе с холстом.

## Как пользоваться
1. **Интерфейсы** — откройте архив `interfaces.pck` или папку с распакованными xml.
2. **Текстуры** — откройте `surfaces.pck` или папку с картинками (иначе вместо картинок будут штриховки).
3. Выберите файл слева. Тяните элементы мышью, меняйте размер за маркеры, правьте свойства справа.
4. `Ctrl+F` — поиск по всем файлам, `Ctrl+S` — сохранить, `Ctrl+Z/Y` — отмена/повтор, `Ctrl+D` — дублировать.

## Если нужен только exe (без сборки)
Берите готовую папку `publish` (UiForge.exe + две `pckdll_x86*.dll`). Установка не требуется.

## Сборка из исходников
Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и Windows.
* Visual Studio 2022: откройте `UiForge.sln`, запустите проект `UiForge.App`.
* Готовая программа: запустите `Сборка_exe.bat` — появится папка `publish`.

## Устройство проекта
| Папка | Что внутри |
|---|---|
| `UiForge.App` | окно программы (WPF): холст, свойства, поиск, выбор цвета |
| `UiForge.UiFormat` | модель xml-интерфейса: схема элементов, чтение/запись |
| `UiForge.Engine.WinPck` | чтение и запись .pck через `pckdll` (две копии dll — чтобы открыть два архива сразу) |
| `UiForge.Core` | общие типы и определение кодировки файлов |

Чтобы научить редактор новому тегу, достаточно добавить запись в `UiForge.UiFormat/UiControlSchema.cs`.
